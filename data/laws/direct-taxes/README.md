# آرشیو محلی قانون مالیات‌های مستقیم

درخواست‌هایی با یکی از الگوهای «م X ق م م» یا «ماده X ق م م» از متن ثبت‌شده در این پوشه پاسخ می‌گیرند. اگر ماده هنوز ذخیره نشده باشد، ربات فقط از صفحهٔ متن تنقیح‌شدهٔ سامانهٔ ملی قوانین و مقررات جمهوری اسلامی ایران تلاش می‌کند همان ماده را بخواند؛ پاسخ منبع از نظر عنوان قانون و شمارهٔ ماده کنترل می‌شود و فقط پس از اعتبارسنجی در `articles/article-X.json` ذخیره خواهد شد. پاسخ مسدودشده، صفحهٔ خطا یا متن مبهم هرگز cache نمی‌شود.

مادهٔ ۱۰ در متن رسمی ذیل فصل دومِ منسوخ‌شده ثبت شده است؛ این وضعیت در ابتدای متن ذخیره‌شده و پاسخ ربات مشخص می‌شود.

منبع رسمی: https://qavanin.ir/Law/TreeText/?IDS=892583840653829785

پس از ثبت موفق ماده، GitHub Actions آن را همراه state به همین مخزن commit می‌کند. از آن پس درخواست‌های همان ماده فقط از فایل محلی خوانده می‌شوند و برای پاسخ‌دادن به آن، دسترسی زنده به سایت لازم نیست. این مخزن عمومی است؛ فایل‌های cacheشده نیز عمومی خواهند بود. تاریخ دریافت و پیوند مرجع داخل هر فایل JSON ثبت می‌شود.
