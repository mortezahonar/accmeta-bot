# قانون کار

الگوی شناسایی‌شده: `ماده X ق ک`؛ ارقام فارسی، عربی و انگلیسی پذیرفته می‌شوند.

بازیابی فعلاً غیرفعال است. PDF ارسالی از دامنهٔ دانشگاه صنعتی اصفهان، طبق فراداده در ۲۰۰۹ ساخته شده و متن مادهٔ ۲۰۳ آن نام قدیمی وزارتخانه را دارد؛ رکورد قاونین مادهٔ ۲۰۳ را اصلاح‌شده در ۱۳۹۰/۰۴/۰۸ نشان می‌دهد. فهرست رسمی وزارت تعاون، کار و رفاه اجتماعی ۱۲ فصل را فهرست می‌کند، اما متن صفحه‌های فصل در این بررسی قابل دریافت نبود. تا تأیید snapshot رسمیِ کامل و اصلاحات، ربات نباید متن حدسی یا نسخهٔ قدیمی را پاسخ دهد. بنا به درخواست کاربر، پیوند منبع در پاسخ تلگرام درج نشود؛ فرادادهٔ منبع باید در آرشیو داخلی حفظ شود.
