# قانون کار

الگوی شناسایی‌شده: `ماده X ق ک`؛ ارقام فارسی، عربی و انگلیسی پذیرفته می‌شوند.

بازیابی تا زمان تأیید نسخهٔ کامل و تنقیح‌شدهٔ رسمی غیرفعال است. رکورد قاونین در بررسی منبع، متن ماده‌ها را در اختیار نگذاشت و نسخهٔ مرکز پژوهش‌های مجلس به‌تنهایی نسخهٔ جاری را اثبات نمی‌کند. ربات در پاسخ به این فرمان متن حدسی ارسال نمی‌کند.
