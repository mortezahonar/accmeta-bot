# استانداردهای حسابداری

الگوی شناسایی‌شده: `استاندارد حسابداری X`؛ ارقام فارسی، عربی و انگلیسی پذیرفته می‌شوند.

بازیابی تا زمان دسترسی و تأیید متن کامل و نسخهٔ رسمیِ مورد استفاده غیرفعال است. فهرست سازمان حسابرسی در بررسی اخیر پاسخ قابل‌استفاده نداد؛ هیچ نسخهٔ قدیمی یا mirror خصوصی جای متن رسمی را نمی‌گیرد. ربات در پاسخ به این فرمان متن حدسی ارسال نمی‌کند.
